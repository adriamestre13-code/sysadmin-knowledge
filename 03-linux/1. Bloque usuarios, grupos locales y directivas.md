# Usuarios, Grupos y Directivas en Ubuntu Desktop

Un entorno cliente local basado en **Ubuntu Desktop 26.04 LTS** requiere la aplicación rigurosa de permisos y directivas del sistema para garantizar el principio de menor privilegio (*Least Privilege*). A través de la gestión de usuarios, el control de acceso mediante Listas de Control de Acceso (ACL) y el endurecimiento de PAM (*Pluggable Authentication Modules*), se logra una infraestructura segura sin depender de un servidor de dominio.

### Objetivos del laboratorio

* **Gestión de Identidades Locales:** Creación y segmentación de usuarios y grupos para los departamentos de **Dirección**, **Profesores** y **Alumnos**.
* **Control de Accesos (POSIX y ACL):** Configuración de la estructura de directorios en `/datos` aplicando permisos avanzados de lectura, modificación y restricción por grupo mediante `chmod` y `setfacl`.
* **Seguridad y Directivas de Cuentas (PAM):** Implementación de políticas de complejidad de contraseñas, historial y vigencia para prevenir accesos no autorizados.
* **Gestión por Consola:** Control total de la administración de usuarios, atributos de cuenta y permisos mediante la terminal de comandos Bash.

### Jerarquía de Directorios y Permisos (POSIX / ACL)

```text
/datos/
├── alumnos/
│   ├── alumnos     ──► Lectura / Escritura (rwx)
│   ├── profesores  ──► Modificación (rwx)
│   └── direccion   ──► Solo lectura (r-x)
│
└── profesores/
    ├── profesores  ──► Lectura / Escritura (rwx)
    ├── direccion   ──► Solo lectura (r-x)
    └── alumnos     ──► Acceso denegado (---)
```

---

### 1. Creación de Usuarios y Grupos Locales

#### A. Creación de Grupos Locales

1. Abrimos la terminal de comandos de Ubuntu (`Ctrl + Alt + T`).
2. Creamos los tres grupos del sistema ejecutando los siguientes comandos:

```bash
sudo groupadd direccion
sudo groupadd profesores
sudo groupadd alumnos
```

#### B. Creación de Usuarios Locales

1. Creamos las cuentas de usuario asignándoles su directorio personal (`/home`) y vinculándolas a su grupo principal correspondiente:

```bash
sudo useradd -m -g direccion -s /bin/bash UserDireccion
sudo useradd -m -g profesores -s /bin/bash UserProfesor
sudo useradd -m -g alumnos -s /bin/bash UserAlumno
```
>

2. Establecemos las contraseñas iniciales para cada uno de los usuarios creados:

```bash
sudo passwd UserDireccion
sudo passwd UserProfesor
sudo passwd UserAlumno
```

### 2. Creación de Estructura de Carpetas y Configuración de Permisos

#### A. Creación del directorio base y subcarpetas

1. Abrimos la terminal (`Ctrl + Alt + T`).
2. Creamos la carpeta principal `/datos` en la raíz del sistema junto con sus dos subcarpetas mediante el parámetro `-p`:

```bash
sudo mkdir -p /datos/alumnos /datos/profesores
```

#### B. Configuración de permisos y Listas de Control de Acceso (ACL)

Para reproducir el comportamiento de permisos avanzados en Linux, asignamos la propiedad básica POSIX y utilizamos ACL (`setfacl`) para gestionar los permisos de Dirección.

##### 1. Carpeta `/datos/alumnos`

1. Asignamos la propiedad al usuario `UserProfesor` y al grupo `alumnos`:

```bash
sudo chown -R UserProfesor:alumnos /datos/alumnos
```
>
> <img width="971" height="620" alt="Captura de pantalla 2026-09-03 213328" src="https://github.com/user-attachments/assets/4f6456fb-6a7a-4e19-8c52-2564d91f7b7b" />

2. Aplicamos permisos base `770` (Propietario: lectura/escritura/ejecución, Grupo: lectura/escritura/ejecución, Otros: sin acceso):

```bash
sudo chmod 770 /datos/alumnos
```
>
> <img width="970" height="620" alt="Captura de pantalla 2026-09-03 213456" src="https://github.com/user-attachments/assets/ddaa753e-ed38-4efb-939f-9e4f032381e2" />

3. Otorgamos permisos ACL de solo lectura y ejecución al grupo `direccion` (para la carpeta actual y para los elementos futuros):
> El primer comando permite la creación de una nueva regla en el directorio especificado (El grupo dirección tenga permisos de lectura y ejecución), el segundo comando, con el modificador `d` permite que los archivos de dicho directorio, hereden estos permisos.
```bash
sudo setfacl -m g:direccion:rx /datos/alumnos
sudo setfacl -d -m g:direccion:rx /datos/alumnos
```

##### 2. Carpeta `/datos/profesores`

1. Asignamos la propiedad al usuario `UserProfesor` y al grupo `profesores`:

```bash
sudo chown -R UserProfesor:profesores /datos/profesores
```

### 3. Configuración de Directivas de Cuentas y Contraseñas (PAM)

#### A. Instalación de los módulos de seguridad PAM

1. Abrimos la terminal (`Ctrl + Alt + T`).
2. Instalamos los paquetes necesarios para gestionar la calidad de contraseñas y el historial:

```bash
sudo apt update && sudo apt install -y libpam-pwquality
```

#### B. Configuración de complejidad, longitud y lista negra

1. Editamos el archivo de configuración de calidad de contraseñas `/etc/security/pwquality.conf`:

```bash
sudo nano /etc/security/pwquality.conf
```
>
> <img width="970" height="623" alt="Captura de pantalla 2026-09-03 215126" src="https://github.com/user-attachments/assets/4cafb672-c232-4c77-8482-5d11caa4488c" />

2. Aplicamos las siguientes directivas de seguridad ajustando sus parámetros:

```text
minlen = 7
ucredit = -2
lcredit = -1
dcredit = -1
ocredit = -1
badwords = P@ssW0ck B@itr#9
```

* `minlen = 7`: Establece la longitud mínima en **7 caracteres**.
* `ucredit = -2`: Exige un mínimo de **2 letras mayúsculas**.
* `lcredit = -1`: Exige un mínimo de **1 letra minúscula**.
* `dcredit = -1`: Exige un mínimo de **1 dígito**.
* `ocredit = -1`: Exige un mínimo de **1 símbolo**.
* `badwords`: Lista de contraseñas explícitamente prohibidas.
>
> <img width="969" height="621" alt="Captura de pantalla 2026-09-03 215506" src="https://github.com/user-attachments/assets/336f22d9-2a2a-4889-a845-01b89e1701d9" />
> **IMPORTANTE:** Recuerda eliminar las almohadillas para que la directiva surta efecto, sino se quedará como un comentario.

#### C. Configuración del historial de contraseñas

1. Editamos el archivo de autenticación para contraseñas de PAM:

```bash
sudo nano /etc/pam.d/common-password
```

2. Localizamos la línea referente a `pam_pwhistory.so` (o la añadimos si no existe) agregando el argumento `remember=3`:

```text
password required pam_pwhistory.so remember=3 use_authtok
```

#### D. Vigencia de la contraseña (60 días)

1. Editamos el archivo global de configuración de inicios de sesión `/etc/login.defs`:

```bash
sudo nano /etc/login.defs
```

2. Modificamos el parámetro de expiración de contraseña a 60 días:

```text
PASS_MAX_DAYS   60
```

3. Aplicamos el límite de 60 días a los usuarios previamente creados en el sistema:

```bash
sudo chage -M 60 UserDireccion
sudo chage -M 60 UserProfesor
sudo chage -M 60 UserAlumno
```
