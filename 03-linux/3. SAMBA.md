# Introducción a SAMBA

Samba es una suite de software de código abierto que implementa el protocolo de red **SMB/CIFS** (*Server Message Block / Common Internet File System*) en sistemas operativos tipo UNIX y Linux. 

Su función principal es permitir la **interoperabilidad y compartición de recursos en redes mixtas**. Gracias a Samba, un servidor Linux (en este caso, Ubuntu Server 26.04 LTS) puede actuar como un servidor de archivos y de impresión nativo para clientes que ejecutan sistemas operativos Windows, permitiendo que estos accedan a carpetas compartidas y gestionen archivos de manera transparente, tal y como lo harían contra un servidor Windows Server.

### Objetivos del Laboratorio

El propósito de esta práctica es implementar, configurar y validar un servicio de almacenamiento compartido mediante Samba, aplicando directivas de control de acceso granulares basadas en usuarios y grupos del sistema local.

Los objetivos específicos a completar son:

1. **Despliegue del servicio:** Instalar y estructurar las dependencias de Samba en un entorno Ubuntu Server 22.04 LTS.
2. **Estructura de directorios:** Crear e integrar el árbol de rutas bajo el directorio base asignado (`/sambaTunombre/`).
3. **Gestión de identidades local:** Configurar los usuarios y grupos locales del sistema Linux necesarios para el control de acceso.
4. **Configuración de recursos compartidos (`smb.conf`):** Definir y parametrizar las directivas de red para 3 recursos compartidos con diferentes niveles de privilegio:
   * **`publica`:** Recurso de acceso público general para lectura, reservando la escritura únicamente al grupo `administradores`.
   * **`oficina`:** Recurso restringido de trabajo colaborativo con acceso exclusivo de lectura y escritura para los grupos `oficina` y `administradores`.
   * **`ASYR1`:** Recurso privado de acceso único e exclusivo para el usuario `ASYR1`.
5. **Validación desde cliente:** Comprobar la correcta aplicación de permisos y autenticación desde una máquina cliente con Windows 11 Pro.
