# Introducción a SAMBA

Samba es una suite de software de código abierto que implementa el protocolo de red **SMB/CIFS** (*Server Message Block / Common Internet File System*) en sistemas operativos tipo UNIX y Linux. 

Su función principal es permitir la **interoperabilidad y compartición de recursos en redes mixtas**. Gracias a Samba, un servidor Linux (en este caso, Ubuntu Server 26.04 LTS) puede actuar como un servidor de archivos y de impresión nativo para clientes que ejecutan sistemas operativos Windows, permitiendo que estos accedan a carpetas compartidas y gestionen archivos de manera transparente, tal y como lo harían contra un servidor Windows Server.

## Objetivos del Laboratorio

A través de esta guía paso a paso, se alcanzarán los siguientes objetivos técnicos:

1. **Configuración de conectividad e infraestructura básica:**
   - Establecer la comunicación IP estática entre el servidor Linux (Ubuntu 26.04 LTS) y la máquina cliente (Windows 11 Enterprise) en un entorno virtual aislado.

2. **Gestión de la estructura del servidor Linux:**
   - Crear el árbol de directorios destinado a los recursos compartidos (`/sambaAdria/publica`, `/sambaAdria/oficina` y `/sambaAdria/ASYR1`).
   - Configurar usuarios y grupos del sistema local (`administradores`, `oficina`, `asyr1`) con sus respectivas Listas de Control de Acceso (ACL) y permisos del sistema de archivos.

3. **Despliegue y administración del servicio SAMBA:**
   - Instalar e inicializar el demonio de SAMBA en el servidor.
   - Editar y parametrizar el archivo de configuración `/etc/samba/smb.conf` estableciendo los niveles de acceso (lectura/escritura, invitados, usuarios válidos).
   - Dar de alta a los usuarios en la base de datos de contraseñas de SAMBA (`smbpasswd`).

4. **Validación y auditoría desde el cliente Windows:**
   - Conectar unidades de red en Windows 11 utilizando diferentes credenciales para verificar la correcta aplicación de los permisos.
   - Auditar desde el servidor las conexiones SMB activas para garantizar la trazabilidad del acceso.

## 1. Configuración de los Nombres de Equipo y Red

### 1.1. Configuración en el Servidor (Ubuntu 22.04 LTS)

1. **Adaptador de Red y Dirección IP Estática:**
   * En VirtualBox, asegúrate de que el adaptador de red de la máquina virtual esté en modo **Red interna** (*intnet*) o **Solo-anfitrión** (*Host-only*).
   * Dentro de Ubuntu, dirígete a **Configuración > Red** (*Settings > Network*), edita el perfil de red de la interfaz cableada (*Wired*) e introduce la siguiente configuración IP manual:
     * **Método IPv4:** Manual
     * **Dirección IP:** `192.168.56.20`
     * **Máscara de subred:** `255.255.255.0` (o `/24`)

3. **Verificación en Terminal:**
   * Abre una terminal y ejecuta el siguiente comando para confirmar que la interfaz tiene asignada la dirección IP correcta:
     ```bash
     ip a
     ```
     >
     > <img width="971" height="610" alt="image" src="https://github.com/user-attachments/assets/341a9df1-d210-44ef-90da-64ff5350bd56" />

### 1.2. Configuración en el Cliente (Windows 11 Enterprise)

1. **Adaptador de Red y Dirección IP Estática:**
   * Asigna el mismo tipo de red en la configuración de la máquina virtual (*Red interna* o *Solo-anfitrión*).
   * En Windows, abre las **Conexiones de red** (`ncpa.cpl`), edita las propiedades de **Propiedades de Protocolo de Internet versión 4 (TCP/IPv4)** y establece los datos estáticos:
     * **Dirección IP:** `192.168.56.10` (o cualquier dirección dentro del rango `192.168.56.X` distinta a la del servidor)
     * **Máscara de subred:** `255.255.255.0`

2. **Verificación en Consola:**
   * Abre la consola de comandos (`cmd`) y comprueba la configuración de red con:
     ```cmd
     ipconfig
     ```

## 2. Comprobación de la Conectividad IP

Una vez asignadas las direcciones estáticas a ambos extremos, es imprescindible validar que existe comunicación bidireccional mediante el comando `ping`.

1. **Comprobación del Servidor al Cliente (Ubuntu -> Windows):**
   * Desde la terminal de Ubuntu, ejecuta:
     ```bash
     ping -c 4 192.168.56.10
     ```
   * Verifica que se reciban de vuelta los 4 paquetes enviando información sin pérdidas.
     >
     > <img width="971" height="609" alt="Captura de pantalla 2026-09-08 200042" src="https://github.com/user-attachments/assets/d88ce509-4404-490c-b6f5-cce70e7decf0" />

2. **Comprobación del Cliente al Servidor (Windows -> Ubuntu):**
   * Desde el `cmd` de Windows, ejecuta:
     ```cmd
     ping 192.168.56.20
     ```
   * Asegúrate de recibir respuesta correcta del servidor Linux.

     > **Importante** desactiva el firewall para realizar la conectividad.
