# Gestión de Particiones y Almacenamiento en Ubuntu Desktop

En entornos GNU/Linux, la gestión del almacenamiento difiere de la estructura habitual basada en letras de unidad de Windows. Linux organiza las particiones dentro de un árbol de directorios único jerárquico donde cada sección del disco se monta sobre un punto específico de la estructura del sistema de archivos.

---

### 1. ¿Para qué sirven las particiones en Linux?

* **Aislamiento del Directorio Raíz (`/`) y Datos (`/home`):** Separar el sistema operativo de los archivos personales permite reinstalar o actualizar la distribución sin afectar a los documentos, configuraciones y datos de los usuarios.
* **Espacio de Intercambio (SWAP):** Permite reservar una partición o archivo dedicado a la memoria virtual cuando la memoria RAM física se satura o se requiere hibernación del sistema.
* **Seguridad y Cuotas de Disco:** Aislar directorios críticos como `/var` o `/tmp` evita que logs de aplicaciones o archivos temporales consuman todo el espacio del sistema principal y provoquen un fallo global.
* **Gestión de Múltiples Sistemas de Archivos:** Permite utilizar formatos nativos como Ext4 junto a otros como FAT32 o NTFS para compartir datos con sistemas Windows.

---

### 2. Estructura de Nombrado y Sistemas de Archivos

A diferencia de las asignaciones por letras (`C:`, `D:`), Linux representa cada disco y partición como un archivo especial dentro del directorio `/dev`:

#### A. Identificación de Dispositivos en `/dev`
* **SATA / IDE / SCSI:** Se nombran como `sdX` donde `X` representa la letra del disco físico (`sda` para el primer disco, `sdb` para el segundo, etc.).
* **Particiones:** Se identifican agregando un número al final del disco (`sdb1`, `sdb2`, `sdb5`).
  * En tablas MBR, las particiones primarias/extendidas se numeran del **1 al 4** (`sdb1` a `sdb4`).
  * Las unidades lógicas dentro de una partición extendida comienzan siempre a partir de **`sdb5`**.

#### B. Sistemas de Archivos Principales
* **Ext4 (Fourth Extended Filesystem):** Es el estándar nativo en Ubuntu. Ofrece alto rendimiento, registro transaccional (*journaling*) y excelente estabilidad.
* **SWAP:** Área especial formateada para uso exclusivo del kernel como memoria virtual suplementaria.
