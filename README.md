#  IT Helpdesk & Systems Administration Brain

¡Bienvenido/a a mi base de conocimiento! Este repositorio funciona como una segunda mente donde documento mi progreso, guías paso a paso, automatizaciones y procedimientos técnicos. 

Mi objetivo en este repositorio es documentar todos y cada uno de mis laboratorios relacionados en el entorno ASIR / IT Helpdesk.

---

##  Áreas de Conocimiento

###  Windows Ecosystem
* **Helpdesk:** Gestión de usuarios, solución de problemas comunes en Windows 10/11, configuración de red local, impresoras y permisos.
* **Sysadmin:** Virtualización, Active Directory (AD DS), Group Policy Objects (GPO), DNS, DHCP, PowerShell scripting y gestión de Windows Server.

###  Linux Ecosystem
* **Helpdesk:** Comandos básicos de terminal, gestión de permisos (`chmod`, `chown`), usuarios y resolución de problemas a nivel de cliente.
* **Sysadmin:** Administración por SSH, gestión de servicios (`systemd`), automatización mediante Bash, seguridad básica y gestión de servidores (Debian/Ubuntu/CentOS).

###  Redes y Servicios Básicos
* Troubleshooting de red (`ping`, `traceroute`, `netstat`, `nslookup`).
* Modelos TCP/IP y OSI aplicados a la práctica.
* Configuración de VPNs, routers y switches básicos.
