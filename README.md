# 🧠 IT Helpdesk & Systems Administration Brain

¡Bienvenido/a a mi base de conocimiento! Este repositorio funciona como una segunda mente donde documento mi progreso, guías paso a paso, automatizaciones y procedimientos técnicos. 

El objetivo es abarcar desde la resolución de incidencias del día a día en nivel **Entry-Level (Helpdesk)** hasta configuraciones más complejas en **Administración de Sistemas**.

---

## 🛠️ Áreas de Conocimiento

### 💻 Windows Ecosystem
* **Helpdesk:** Gestión de usuarios, solución de problemas comunes en Windows 10/11, configuración de red local, impresoras y permisos.
* **Sysadmin:** Active Directory (AD DS), Group Policy Objects (GPO), DNS, DHCP, PowerShell scripting y gestión de Windows Server.

### 🐧 Linux Ecosystem
* **Helpdesk:** Comandos básicos de terminal, gestión de permisos (`chmod`, `chown`), usuarios y resolución de problemas a nivel de cliente.
* **Sysadmin:** Administración por SSH, gestión de servicios (`systemd`), automatización mediante Bash, seguridad básica y gestión de servidores (Debian/Ubuntu/CentOS).

### 🌐 Redes y Servicios Básicos
* Troubleshooting de red (`ping`, `traceroute`, `netstat`, `nslookup`).
* Modelos TCP/IP y OSI aplicados a la práctica.
* Configuración de VPNs, routers y switches básicos.

---

## 📂 Estructura del Repositorio

* `/01-helpdesk/` - Guías de soporte técnico, atención al usuario y resolución de incidencias rápido.
* `/02-sysadmin/` - Documentación avanzada de servidores, servicios y arquitectura.
* `/03-scripts/` - Scripts útiles en PowerShell y Bash para automatizar tareas repetitivas.
* `/04-templates/` - Plantillas de informes de incidentes y procedimientos operativos estándar (SOP).

---

Documentar todo lo aprendido para mantener una referencia rápida en el trabajo diario, afianzar conceptos clave de la industria y servir como portafolio técnico.
