#  Arranque dual: Windows 11 Enterprise + Ubuntu Desktop 26.04 LTS

Guía paso a paso para establecer un arranque dual con Windows 11 y Ubuntu Desktop.

Un entorno de **arranque dual (Dual Boot)** permite instalar y ejecutar dos sistemas operativos independientes en una misma máquina, seleccionando cuál iniciar al encender el equipo. Esta configuración resulta especialmente útil en entornos de laboratorio, desarrollo y administración de sistemas por diversos motivos:

* **Especialización de herramientas:** Permite disponer de **Windows 11 Enterprise** para software corporativo, entornos Active Directory o herramientas específicas de administración, manteniendo simultáneamente **Ubuntu Desktop 26.04 LTS** para desarrollo en Linux, scripting Bash, despliegue de contenedores y gestión de servidores.
* **Aislamiento y rendimiento nativo:** A diferencia de la virtualización convencional sobre un sistema operativo anfitrión, el arranque dual garantiza que cada SO acceda de forma directa al hardware (CPU, RAM y GPU), optimizando los recursos y aislando los entornos de trabajo.
* **Pruebas de compatibilidad y red:** Ofrece un escenario idóneo para simular despliegues reales, probar la convivencia de sistemas de archivos (como NTFS y ext4) y analizar el comportamiento de cargadores de arranque UEFI en entornos híbridos.

##  Instalación

1. **Selección del dispositivo de arranque:**
   Encendemos la máquina virtual, hacemos clic rápidamente dentro de la ventana y pulsamos la tecla `ESC` para acceder al menú EFI/BIOS de VirtualBox. A continuación, nos dirigimos a la opción **Boot Manager**, pulsamos `Enter` y seleccionamos la unidad óptica para iniciar desde la ISO de Ubuntu.

3. **Modificación del arranque dual:**
   * **¡Importante!** Genera una snapshot antes de continuar, esto nos ayudará a restaurar el sistema en caso de estropear algo.
   * Una vez comprobemos que el sistema dual funciona a la perfección, pasaremos a su posterior configuración. Para ello, entraremos en Ubuntu y modificaremos los valores a través de la terminal. Los valores a modificar serán los siguientes:
        1. Cambiar el tiempo de espera del menú de arranque a 40 segundos.
        2. Que el sistema predeterminado de arranque sea Windows 11.
        3. Cambiar el nombre de Ubuntu en el gestor de arranque.
   >
   >```bash
   >sudo nano /etc/default/grub
   >```
