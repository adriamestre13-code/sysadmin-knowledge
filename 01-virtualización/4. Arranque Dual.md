#  Arranque dual: Windows 11 Enterprise + Ubuntu Desktop 26.04 LTS

Guía paso a paso para establecer un arranque dual con Windows 11 y Ubuntu Desktop.

---

##  Preparación

En los anteriores apartados ya hemos creado distintas MV y se han dejado actualizadas y preparadas para su funcionamiento, por lo que para completar este apartado simplemente clonaremos la MV de Windows que ya tenemos configurada.
>
> <img width="530" height="302" alt="Captura de pantalla 2026-09-03 164400" src="https://github.com/user-attachments/assets/06f140b1-3bfb-400a-a934-97cf5c79a252" />
> <img width="612" height="386" alt="Captura de pantalla 2026-09-03 164651" src="https://github.com/user-attachments/assets/84e5dd47-0cde-4c2c-9a3d-11be6a2e557c" />

Una vez clonada, deberemos fijarnos en *Sistema > Placa Base* y marcar la casilla UEFI, esta nos bloqueará el *Boot Device Order* puesto que UEFI gestiona el arranque de forma dinámica mediante variables internas.
>
><img width="613" height="386" alt="Captura de pantalla 2026-09-03 165119" src="https://github.com/user-attachments/assets/e761680d-3135-4d31-8820-d36b306ebc04" />

##  Instalación

* **Oracle VirtualBox** instalado.
* [**ISO de Ubuntu Desktop**](https://ubuntu.com/download/desktop) (versión LTS descargable desde el sitio web oficial de Ubuntu).
