# Conectividad de Red entre Equipos (Windows y Linux)

La interconexión de sistemas operativos heterogéneos es un pilar fundamental en la administración de sistemas. Configurar de forma manual la dirección IP, la máscara de subred y probar la comunicación mediante tramas de red permite establecer canales de comunicación directos entre clientes y servidores dentro de un segmento local aislado.

Este laboratorio aborda la configuración de parámetros de red estáticos en una máquina virtual con Windows 11 Pro para garantizar la conectividad punto a punto con otro sistema dentro de una red privada.

### 🎯 Objetivos del laboratorio

* **Asignación de Parámetros de Red:** Configurar manualmente direcciones IP privadas estáticas y máscaras de subred.
* **Gestión Multicanal (GUI / CLI):** Aplicar configuraciones de red tanto desde el entorno gráfico como desde la consola de comandos mediante la utilidad `netsh`.
* **Verificación de Conectividad:** Diagnosticar la resolución de direcciones y la conectividad lógica entre máquinas virtuales.

---

### 🧠 Fundamentos Teóricos: Funcionamiento de las Redes Locales

Para que dos equipos puedan comunicarse dentro de una misma red local (LAN) sin necesidad de pasar por un enrutador o salir a Internet, deben cumplir las siguientes condiciones:

1. **Segmento de red común:** Ambas máquinas deben tener direcciones IP dentro del mismo rango definido por la máscara de subred (por ejemplo, en un rango `192.168.100.0/24`, los IPs varían entre `192.168.100.1` y `192.168.100.254`).
2. **Modo de red en la máquina virtual:** Debe utilizarse el modo **Red Interna** (*Internal Network*) o **Solo-Anfitrión** (*Host-Only*). Este modo crea un conmutador (*switch*) virtual donde las máquinas enviarán y recibirán tramas Ethernet de forma aislada.
3. **Ausencia de puerta de enlace y DNS:** Al ser una comunicación directa en capa 2/3 dentro del mismo segmento local, no se requiere configurar una Puerta de Enlace (*Default Gateway*) ni Servidores DNS, ya que no existe tráfico que deba salir fuera de la red.

### 1. Configuración de IP Estática en Windows 11 Pro

Para este ejemplo, utilizaremos el rango privado `192.168.100.0/24` y asignaremos a la máquina de Windows la IP `192.168.100.10` con máscara `255.255.255.0`.

#### A. Configuración desde la Interfaz Gráfica (GUI)

1. Abrimos el menú **Ejecutar** (`Windows + R`), escribimos `ncpa.cpl` y pulsamos **Enter** para abrir las *Conexiones de red*.
2. Hacemos clic derecho sobre la tarjeta de red (por ejemplo, *Ethernet*) y seleccionamos **Propiedades**.
3. En la lista, seleccionamos **Protocolo de Internet versión 4 (TCP/IPv4)** y hacemos clic en **Propiedades**.
4. Marcamos la opción **Usar la siguiente dirección IP** e introducimos:
   * **Dirección IP:** `192.168.100.10`
   * **Máscara de subred:** `255.255.255.0`
   * **Puerta de enlace predeterminada:** *(En blanco)*
5. Dejamos vacíos los campos de DNS y hacemos clic en **Aceptar** > **Cerrar**.

---

#### B. Configuración desde la Consola de Comandos (`netsh`)

1. Abrimos la consola de comandos (**CMD**) con privilegios de administrador.
2. Identificamos el nombre exacto de la interfaz de red ejecutando:

```cmd
netsh interface ipv4 show interfaces
```

3. Asignamos la IP estática y la máscara de subred a la interfaz (asumiendo que se llama `Ethernet`):

```cmd
netsh interface ipv4 set address name="Ethernet" static 192.168.100.10 255.255.255.0
```

---

#### C. Comprobación de la Configuración

1. En la consola de comandos, verificamos que los parámetros se hayan aplicado correctamente:

```cmd
ipconfig /all
```

2. Confirmamos la visualización de la dirección IPv4 asignada (`192.168.100.10`) y la máscara de subred (`255.255.255.0`).
