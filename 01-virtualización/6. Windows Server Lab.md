# Creación de una Máquina Virtual con Windows Server 2022 Datacenter

Guía paso a paso para desplegar Windows Server 2022 en Oracle VirtualBox y la justificación técnica de cada ajuste.

---

## ¿Por qué Windows Server 2022 Datacenter?

A diferencia de las versiones de cliente o la edición Standard, la edición **Datacenter** está optimizada para la infraestructura de red corporativa y la virtualización avanzada:
* **Active Directory Domain Services (AD DS):** Gestión centralizada de identidades, usuarios, equipos y directivas de grupo (GPOs) en la red.
* **Derechos de virtualización ilimitados:** Permite ejecutar un número ilimitado de instancias virtuales dentro del mismo hipervisor licenciado.
* **Storage Spaces Direct (S2D) y Shielded VMs:** Tecnologías avanzadas para crear almacenamiento definido por software y máquinas virtuales blindadas contra accesos no autorizados.
* **Rol de Servidor completo:** Soporte nativo para servicios esenciales de infraestructura como DHCP, DNS, IIS (Web) y Servicios de Archivos.

##  Configuración Paso a Paso de la VM (y su explicación)

### 1. Nombre y Sistema Operativo
* **Tipo:** Microsoft Windows
* **Versión:** Windows 2022 (64-bit)
>
> <img width="601" height="412" alt="image" src="https://github.com/user-attachments/assets/f358fe9f-ee43-47ce-bb7d-ec48a03af37d" />

* **IMPORTANTE:** Desmarcar la casilla **Proceder con la instalación desatendida**, esto nos permitirá tener control total sobre la selección del idioma, la edición con interfaz gráfica y la configuración de particiones durante el instalador.

### 2. Memoria RAM y Procesadores (CPU)
* **RAM:** 2048 MB (2 GB) mínimo / 4096 MB (4 GB) o más recomendado para laboratorios con Active Directory y roles activos.
* **CPUs:** 2 vCPUs recomendado para garantizar una respuesta fluida del sistema operativo.
* **Habilitar EFI:** Opcional (se puede dejar desmarcado usando BIOS tradicional o activado usando EFI/UEFI).
> **¿Por qué?** Aunque los requisitos mínimos de Microsoft para la instalación de servidor indican 512 MB de RAM y 1 CPU, asignarle 4 GB de RAM y 2 vCPUs garantiza que la consola de Server Manager y los servicios de red respondan correctamente durante las prácticas.
>
> <img width="601" height="410" alt="image" src="https://github.com/user-attachments/assets/8ae5c043-59fe-4e5c-93db-341e01d428e0" />

### 3. Disco Duro Virtual
* **Tamaño:** 50 GB mínimo (150 GB recomendado para el lab).
* **Tipo de archivo:** VDI (VirtualBox Disk Image).
* **Espacio asignado:** Desmarcar la opción de Reservar tamaño completo (*Reservado dinámicamente*).
> **¿Por qué?** La asignación dinámica evita ocupar de golpe todo el tamaño asignado en el disco de tu máquina física; el archivo del disco virtual irá creciendo a medida que el servidor instale componentes y datos.
>
> <img width="601" height="413" alt="image" src="https://github.com/user-attachments/assets/4ac25448-989e-4f15-b220-8bdc06d0da10" />

### 4. Configuración de Red
* **Modo de red:** NAT (para descargas iniciales y actualizaciones) o Red Interna / Adaptador Puente (para simulaciones de dominio corporativo, gestión de DHCP, DNS y comunicación exclusiva entre clientes y el servidor).
> **¿Por qué?** En entornos de laboratorio con Windows Server, configurar un adaptador en modo Red Interna o Puente permite aislar o simular adecuadamente la infraestructura de red sin interferir con el router real de casa o trabajo.

## Proceso de Instalación

1. Inicia la VM en VirtualBox y selecciona el archivo ISO de Windows Server 2022 montado en la unidad óptica virtual.
2. Presiona cualquier tecla al iniciar cuando aparezca el mensaje *“Press any key to boot from CD or DVD...”*.
3. Configura el idioma de instalación, el formato de hora y moneda, y la distribución del teclado.
4. Presiona sobre **Instalar ahora**.
5. Selecciona la edición **Windows Server 2022 Datacenter (Evaluación con experiencia de escritorio)** / *(Desktop Experience)*.
   > **Atención:** Si seleccionas la opción estándar sin "Experiencia de escritorio", se instalará la versión *Server Core* (solo consola de comandos PowerShell sin interfaz gráfica).
6. Acepta los términos de la licencia de software de Microsoft.
7. Selecciona el tipo de instalación **Personalizada: instalar solo Windows (avanzado)**.
8. En la ventana de gestión de discos, selecciona el disco no asignado, crea el esquema de particiones deseado y haz clic en **Siguiente** para iniciar la copia de archivos.

* Añade una contraseña para el usuario administrador: `p@ssw0rd`
>
> <img width="509" height="445" alt="image" src="https://github.com/user-attachments/assets/76040b46-e39b-4ac9-a0e8-77086abcb8b9" />

* Instala [**VirtualBox Guest Additions**](https://github.com/adriamestre13-code/sysadmin-knowledge/blob/main/01-virtualizaci%C3%B3n/2.%20Windows%20Enterprise%20Lab.md) (*Dispositivos > Insertar imagen de CD de las Guest Additions*) una vez iniciado el escritorio para habilitar la resolución automática de pantalla y el portapapeles compartido.
