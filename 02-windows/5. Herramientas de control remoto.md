# Implementación de Herramientas de Control Remoto en Windows 11

Las herramientas de control remoto son aplicaciones de software que permiten a un usuario acceder, gestionar y manipular un dispositivo informático a distancia desde otra ubicación a través de una red local o de Internet[cite: 1]. Mediante estas utilidades, se transmite en tiempo real la interfaz gráfica del equipo remoto al dispositivo local, permitiendo controlar el teclado y el ratón, transferir archivos y realizar configuraciones o tareas administrativas como si se estuviera físicamente frente a la máquina objetivo[cite: 1]. Su uso es fundamental en el ámbito de la administración de sistemas informáticos, el soporte técnico y el trabajo colaborativo, ya que optimiza los tiempos de respuesta y reduce notablemente los costes operativos asociados al desplazamiento[cite: 1].

## Objetivos del Laboratorio
* **Establecer conectividad de red:** Configurar dos máquinas virtuales con Windows 11 Pro dentro de un segmento de red local simulado y verificar la correcta comunicación entre ellas.
* **Implementar Escritorio Remoto de Windows:** Habilitar, configurar y documentar el uso de la herramienta nativa de control remoto de Microsoft para establecer una sesión remota.
* **Desplegar un software de terceros:** Instalar y configurar AnyDesk en los entornos cliente, ajustando parámetros esenciales de seguridad y uso.
* **Validar accesos remotos:** Comprobar y documentar paso a paso la conectividad activa y el control de la interfaz entre los sistemas.
* **Evaluar y justificar la elección de software:** Analizar los beneficios de despliegue y soporte entre soluciones integradas y de terceros para un entorno empresarial.
