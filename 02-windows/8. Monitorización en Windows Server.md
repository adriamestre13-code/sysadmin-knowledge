# Monitorización, Auditoría y Eventos en Windows Server 2022

En entornos empresariales, la administración de sistemas informáticos requiere mantener un control exhaustivo sobre la integridad de los datos y el estado de los componentes del sistema[cite: 1]. La monitorización y auditoría en Windows Server 2022 permiten vigilar de forma continua la actividad operativa del servidor y de las máquinas cliente asociadas[cite: 1]. Esto ayuda a garantizar una infraestructura estable y a detectar incidencias antes de que comprometan el servicio[cite: 1].

A través del visor de sucesos y las directivas de seguridad, los administradores pueden registrar cambios en las configuraciones, controlar los accesos de los usuarios y centralizar los registros para simplificar el diagnóstico de errores[cite: 1].

---

## Objetivos del laboratorio

En este laboratorio práctico en formato de guía se cumplirán los siguientes objetivos de monitorización y auditoría en Windows Server 2022[cite: 1]:

- **Identificación y análisis de registros (Logs del sistema):**
  - Inspeccionar los principales registros de eventos del sistema (Aplicación, Seguridad, Instalación y Sistema) en Windows Server 2022 y cliente Windows 11.
  - Identificar eventos de error específicos (como el evento de activación de licencia 8200 o el apagado no programado 6008) y documentar su resolución técnica.

- **Auditoría de seguridad y gestión de usuarios:**
  - Configurar directivas de grupo (GPO) para el control de contraseñas y el bloqueo de cuentas ante intentos fallidos de inicio de sesión.
  - Activar el registro de auditoría para el inicio de sesión, la administración de cuentas y el acceso a objetos en el dominio.
  - Validar los registros de auditoría generados por la creación, modificación y eliminación de usuarios, grupos y archivos en recursos compartidos.

- **Recolección y suscripción centralizada de eventos:**
  - Configurar la administración remota de Windows (WinRM) en la máquina cliente.
  - Asignar permisos y crear una suscripción de eventos centralizada en Windows Server 2022.
  - Verificar la recepción remota de eventos del cliente en el visor de sucesos del servidor.
