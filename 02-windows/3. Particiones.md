# Gestión de Particiones y Estructura de Discos en Windows 11

El almacenamiento secundario en cualquier sistema operativo requiere una organización lógica previa antes de alojar datos o instalar sistemas de archivos. La partición de discos es el proceso mediante el cual se divide un medio de almacenamiento físico en secciones independientes, permitiendo gestionar el espacio de forma estructurada, aislar el sistema operativo de los datos de usuario y aplicar diferentes esquemas de seguridad o formato.

---

### 1. ¿Para qué sirven las particiones?

* **Aislamiento del Sistema Operativo:** Permiten separar los archivos críticos del sistema de los archivos personales del usuario, facilitando tareas de respaldo o reinstalación del SO sin pérdida de datos.
* **Organización del Almacenamiento:** Habilitan la creación de múltiples volúmenes lógicos asignados a propósitos específicos (bases de datos, máquinas virtuales, archivos de sistema).
* **Soporte Multiarranque (Multi-boot):** Permiten instalar diferentes sistemas operativos en un mismo disco físico mediante sectores de arranque independientes.
* **Optimización de Seguridad y Permisos:** Facilitan la aplicación de directivas de cifrado (como BitLocker) o permisos de acceso a nivel de volumen completo.

---

### 2. Modelos y Esquemas de Partición

Para definir cómo se escriben y gestionan las tablas de particiones en un disco físico, existen dos modelos principales:

#### A. MBR (Master Boot Record)
Es el estándar tradicional de tabla de particiones utilizado desde principios de los años 80. Almacena la tabla de particiones en el primer sector del disco (Sector 0) junto con el código de arranque principal.

* **Límite de Capacidad:** Soporta un tamaño máximo de disco de **2 TB**.
* **Tipos de Partición:**
  * **Partición Primaria:** Contiene el sector de arranque y puede alojar un sistema operativo. MBR admite un máximo de **4 particiones primarias**.
  * **Partición Extendida:** Tipo especial de partición primaria creada para superar la restricción de 4 particiones. Solo puede existir 1 por disco.
  * **Partición Lógica:** Divisiones creadas dentro de la partición extendida para almacenar datos o sistemas secundarios.
* **Compatibilidad:** Diseñado para sistemas con firmware **BIOS tradicional** (o UEFI en modo CSM/Legacy).
* Estructura MBR (Máximo 4 entradas en total)
├── Escenario A: 4 Primarias  → [ Primaria 1 ] [ Primaria 2 ] [ Primaria 3 ] [ Primaria 4 ]
└── Escenario B: 3 + Extendida → [ Primaria 1 ] [ Primaria 2 ] [ Primaria 3 ] [ Extendida (Lógicas...) ]

#### B. GPT (GUID Partition Table)
Es el estándar moderno que reemplaza a MBR como parte de las especificaciones UEFI. 

* **Capacidad:** Soporta discos de hasta **9.4 ZB** (Zettabytes).
* **Estructura:** Permite hasta **128 particiones primarias** sin necesidad de particiones extendidas o lógicas.
* **Redundancia:** Incluye copias de seguridad de la tabla de particiones al final del disco y comprobaciones de integridad CRC32.
* **Compatibilidad:** Requisito nativo para sistemas con firmware **UEFI** (necesario en Windows 11).
