# Introducción a Active Directory Domain Services (AD DS)

**Active Directory Domain Services (AD DS)** es el servicio de directorio desarrollado por Microsoft para redes de ámbito empresarial. Funciona como una base de datos centralizada y distribuida que almacena y organiza la información sobre todos los recursos de una red informática (usuarios, equipos, grupos, impresoras y políticas de seguridad).

Para poder proceder con este laboratorio, antes mirar la documentación de como preparar una MV de [**Windows Server**](https://github.com/adriamestre13-code/sysadmin-knowledge/blob/main/01-virtualizaci%C3%B3n/6.%20Windows%20Server%20Lab.md).

---

## ¿Para qué sirve Active Directory?

* **Gestión Centralizada de Identidades:** Permite a los administradores crear, modificar y gestionar cuentas de usuario y permisos desde un único punto de control.
* **Autenticación Unificada (Single Sign-On / SSO):** Los usuarios pueden iniciar sesión en cualquier equipo del dominio utilizando un único conjunto de credenciales autorizadas.
* **Aplicación de Directivas de Grupo (GPO):** Permite desplegar configuraciones de seguridad, restricciones, software y preferencias de forma masiva y automatizada en todos los equipos vinculados.
* **Estructuración Jerárquica:** Organiza los recursos mediante **Unidades Organizativas (OU)**, dominios, árboles y bosques, adaptándose a la estructura real de cualquier empresa.
* **Seguridad y Control de Acceso:** Garantiza que cada usuario acceda únicamente a los recursos y carpetas compartidas para los que tiene autorización explícita.

## Objetivos del laboratorio

* **Instalación y Despliegue de Roles:**
  * Preparación de la máquina virtual base con Windows Server 2022 (configuración de nombre de equipo `SRVTunombre`, red e IP estática).
  * Instalación de los roles **Active Directory Domain Services (AD DS)** y **DNS Server**.
  * Promoción del servidor a Controlador de Dominio (creación de un nuevo bosque `Tunombre.lab`).

* **Configuración del Servicio DNS:**
  * Activación de *Automatic Scavenging* a nivel de servidor para el borrado de registros obsoletos.
  * Habilitación de *Scavenge Stale Resource Records* (*Aging*) en la zona de búsqueda directa (*Forward Lookup Zone*).
  * Verificación de resolución de nombres a través de `ping`, `cmd` y cmdlets de PowerShell (`Get-ADDomain` y `Get-ADComputer`).

* **Estructura Lógica e Identidades en AD:**
  * Creación de Unidades Organizativas (OU): `Usuarios` y `Grupos`.
  * Creación de cuentas de usuario (`usuario1`, `usuario2`, `usuario3`, `comercial`, `infor`, `boss`) con contraseñas estandarizadas.
  * Creación de grupos de seguridad (`Administración`, `Alumnos`, `Dirección`, `Comerciales`, `Informática`) y asignación de usuarios a sus respectivos grupos.

* **Administración de Recursos y Permisos (Servidor de Archivos):**
  * Creación de estructura de directorios (`C:\public` y `C:\datos\...`).
  * Configuración de permisos de red compartida (*Share Permissions*) y permisos del sistema de archivos (*NTFS Security*).
  * Control del principio de mínimo privilegio (lectura, modificación y control total según departamento).

* **Integración y Validación de Clientes Windows 11:**
  * Configuración TCP/IP del cliente con DNS apuntando al Controlador de Dominio.
  * Unión exitosa del equipo cliente al dominio de Active Directory.
  * Validación de inicio de sesión con diferentes identidades del dominio.
  * Verificación técnica de permisos de acceso a carpetas compartidas desde el equipo cliente.

* **Directivas de Inicio de Sesión y Restricciones:**
  * Restricción del horario de inicio de sesión (*Logon Hours*) para usuarios estudiantes/alumnos.
  * Habilitación de la directiva de seguridad local para forzar el cierre/bloqueo de sesión fuera de horario.
  * Configuración de restricciones de equipo (*Log on to...*) para permitir el acceso únicamente a estaciones de trabajo autorizadas.

* **Implementación y Blindaje con Directivas de Grupo (GPO):**
  * Creación de la OU `Estudiantes` y creación/enlazado de una GPO dedicada.
  * Ocultar iconos del escritorio y opciones de apagado/reinicio en el menú de inicio.
  * Mostrar extensiones de archivos para todos los usuarios.
  * Ocultar el Panel de Control y deshabilitar el Administrador de Tareas.
  * Deshabilitar el menú contextual (clic derecho) en la barra de tareas y el menú de inicio.
  * Deshabilitar el acceso a la consola de comandos (`cmd`) y las herramientas de edición del Registro (`regedit`).
  * Ocultar la pestaña "Opciones de carpeta" en el Explorador de Windows.
  * Personalizaciones de entorno (fondo de pantalla corporativo y ejecución automática de aplicaciones al iniciar sesión).

* **Delegación de Control y Permisos Administrativos:**
  * Delegación de permisos específicos al grupo `Informática` para unir equipos al dominio dentro del contenedor `Computers`.
  * Verificación de la unión de nuevas estaciones de trabajo utilizando únicamente credenciales de un usuario del grupo delegado.

### 1.1. Instalación de los Roles de Active Directory y DNS

1. Abre el **Server Manager** (Administrador del Servidor).
2. Haz clic en **Manage** (Gestionar) en la esquina superior derecha y selecciona **Add Roles and Features** (Agregar roles y características).
3. En la ventana del asistente (*Before you begin*), haz clic en **Next**.
4. En **Installation Type**, selecciona **Role-based or feature-based installation** y pulsa **Next**.
5. En **Server Selection**, confirma que tu servidor (`SRVAdria`) está seleccionado y pulsa **Next**.
6. En **Server Roles**, marca las siguientes casillas:
   * **Active Directory Domain Services** *(Acepta la ventana emergente que pide agregar características adicionales haciendo clic en "Add Features")*.
   * **DNS Server** *(Acepta la ventana emergente haciendo clic en "Add Features")*.
7. Haz clic en **Next** en la sección de **Roles**, en la de **Features** (asegúrate de que *.NET Framework 4.8* y *Group Policy Management* sigan marcados) y en las pantallas informativas de AD DS y DNS.
8. En **Confirmation**, marca la casilla **Restart the destination server automatically if required** y haz clic en **Install**.
9. Espera a que la barra de progreso finalice y haz clic en **Close**.

### 1.2. Promoción a Controlador de Dominio (Creación del Bosque)

1. En la parte superior del **Server Manager**, haz clic en el icono de la **bandera con el triángulo amarillo de advertencia**.
2. Selecciona **Promote this server to a domain controller** (Promover este servidor a controlador de dominio).
3. En la pantalla **Deployment Configuration**:
   * Selecciona la opción **Add a new forest** (Agregar un nuevo bosque).
   * En **Root domain name**, escribe tu nombre de dominio: `Tunombre.lab` *(por ejemplo: `Adria.lab`)*.
   * Haz clic en **Next**.
4. En **Domain Controller Options**:
   * Deja los niveles funcionales de Bosque y Dominio en **Windows Server 2016**.
   * Asegúrate de que las casillas **Domain Name System (DNS) server** y **Global Catalog (GC)** estén marcadas.
   * En **Password**, introduce tu contraseña de restauración (DSRM): `p@ssword`.
   * Haz clic en **Next**.
5. En **DNS Options**, ignora la advertencia de delegación y pulsa **Next**.
6. En **Additional Options**, confirma que el nombre **NetBIOS** se asigna automáticamente *(por ejemplo: `ADRIA`)* y pulsa **Next**.
7. En **Paths**, deja las rutas por defecto para la base de datos, logs y SYSVOL, y pulsa **Next**.
8. En **Review Options**, revisa el resumen y pulsa **Next**.
9. En **Prerequisites Check**, verifica que aparezca el icono verde indicando que todas las comprobaciones previas pasaron correctamente.
10. Haz clic en **Install**. El servidor aplicará los cambios y se **reiniciará automáticamente**.

## 2. Configuración del Servicio DNS

### 2.1. Activar el Borrado Automático (Automatic Scavenging) en el Servidor

1. Abre el **Administrador del Servidor** (*Server Manager*).
2. Haz clic en **Herramientas** (*Tools*) en la esquina superior derecha y selecciona **DNS**.
3. En la consola de DNS, haz clic derecho sobre el nombre de tu servidor (`SRVTunombre`) y selecciona **Propiedades** (*Properties*).
4. Ve a la pestaña **Avanzadas** (*Advanced*).
5. Marca la casilla **Habilitar el borrado automático de registros obsoletos** (*Enable automatic scavenging of stale records*).
6. Haz clic en **Aplicar** (*Apply*) y luego en **Aceptar** (*OK*).
> <img width="698" height="587" alt="image" src="https://github.com/user-attachments/assets/3e1567a3-0fb2-4fff-a66f-c6d5cf4222b9" />

### 2.2. Configurar el Envejecimiento (Aging/Scavenging) en la Zona del Dominio

1. En la misma consola DNS, despliega el árbol de tu servidor y abre la carpeta **Zonas de búsqueda directa** (*Forward Lookup Zones*).
2. Haz clic derecho sobre la zona con el nombre de tu dominio (`Tunombre.lab`) y selecciona **Propiedades** (*Properties*).
3. En la pestaña **General**, haz clic en el botón **Envejecimiento/Caducidad...** (*Aging...*).
4. Marca la casilla **Realizar el borrado de registros recursos no actualizados** (*Scavenge stale resource records*).
5. Deja los intervalos por defecto (7 días para *No-refresh interval* y 7 días para *Refresh interval*).
6. Haz clic en **Aceptar** (*OK*) en ambas ventanas para guardar.

## 3. Estructura Lógica e Identidades en Active Directory (AD DS)

### 3.1. Creación de las Unidades Organizativas (OU)

1. Abre el **Administrador del Servidor** (*Server Manager*).
2. En la esquina superior derecha, haz clic en **Herramientas** (*Tools*) y selecciona **Usuarios y equipos de Active Directory** (*Active Directory Users and Computers*).
3. En el panel izquierdo, despliega y selecciona la raíz de tu dominio (`Tunombre.lab`).
4. Haz clic derecho sobre el dominio (`Tunombre.lab`) $\rightarrow$ **Nuevo** (*New*) $\rightarrow$ **Unidad organizativa** (*Organizational Unit*).
5. En el campo nombre, escribe **`Usuarios`** (asegúrate de mantener marcada la casilla de protección contra eliminación accidental) y haz clic en **Aceptar**.
6. Repite el proceso sobre la raíz del dominio para crear una segunda Unidad Organizativa llamada **`Grupos`**.

1. En el panel izquierdo, selecciona la Unidad Organizativa **`Usuarios`**.
2. Haz clic derecho en el espacio en blanco del panel derecho $\rightarrow$ **Nuevo** (*New*) $\rightarrow$ **Usuario** (*User*).

## 4. Administración de Recursos y Permisos (Servidor de Archivos)

### 4.1. Creación de la Estructura de Directorios

1. Abre el **Explorador de archivos** en tu Windows Server.
2. Navega al disco local **`C:\`** y crea la carpeta **`public`** (Ruta final: `C:\public`).
3. En la raíz del disco **`C:\`**, crea la carpeta raíz **`datos`** (Ruta final: `C:\datos`).
4. Dentro de la carpeta `C:\datos`, crea las siguientes subcarpetas específicas por departamento:
   * **`alumnos`** (`C:\datos\alumnos`)
   * **`direccion`** (`C:\datos\direccion`)
   * **`comercial`** (`C:\datos\comercial`)
   * **`informatica`** (`C:\datos\informatica`)
   * **`administracion`** (`C:\datos\administracion`)

### 4.2. Configuración de Recursos Compartidos (Share Permissions)

Para cada carpeta creada, haz clic derecho sobre ella $\rightarrow$ **Propiedades** $\rightarrow$ pestaña **Compartir** (*Sharing*) $\rightarrow$ **Uso compartido avanzado...** (*Advanced Sharing*):

1. Marca **Compartir esta carpeta** (*Share this folder*).
2. Haz clic en el botón **Permisos** (*Permissions*).
3. Configura los permisos de red según la siguiente tabla:

| Ruta del recurso | Nombre del recurso | Usuarios/Grupos con acceso | Permisos de red (*Share Permissions*) |
| :--- | :--- | :--- | :--- |
| `C:\public` | `Public` | Administrators / Domain Users | Control Total (*Full Control*) |
| `C:\datos` | `Datos` | Administrators / Domain Users | Control Total (*Full Control*) |
| `C:\datos\alumnos` | `Alumnos` | Administrators / Alumnos | Control Total (*Full Control*) |
| `C:\datos\direccion` | `Direccion` | Administrators / Dirección | Control Total (*Full Control*) |
| `C:\datos\comercial` | `Comercial` | Administrators / Comerciales | Control Total (*Full Control*) |
| `C:\datos\informatica` | `Informatica` | Administrators / Informática | Control Total (*Full Control*) |
| `C:\datos\administracion` | `Administracion` | Administrators / Administración / Dirección / Comerciales | Control Total (*Full Control*) |
>

### 4.3. Configuración de Seguridad Local y Sistema de Archivos (NTFS)

Ajusta los permisos del sistema de archivos accediendo a cada carpeta $\rightarrow$ clic derecho $\rightarrow$ **Propiedades** $\rightarrow$ pestaña **Seguridad** (*Security*) $\rightarrow$ **Opciones avanzadas** (*Advanced*). Deshabilita la herencia (*Disable inheritance*) según sea necesario y asigna los siguientes permisos NTFS locales:

| Carpeta | Grupo / Usuario | Permisos NTFS de seguridad |
| :--- | :--- | :--- |
| `C:\public` | Administrators / Domain Users | **Control Total** |
| `C:\datos` | Administrators<br>Domain Users | **Control Total**<br>**Mostrar el contenido de la carpeta** (*List folder contents*) |
| `C:\datos\alumnos` | Administrators / Dirección<br>Alumnos | **Control Total**<br>**Modificar** (*Modify*) |
| `C:\datos\direccion` | Administrators / Dirección | **Control Total** |
| `C:\datos\comercial` | Administrators / Comerciales | **Control Total** |
| `C:\datos\informatica` | Administrators / Dirección<br>Informática | **Control Total**<br>**Modificar** (*Modify*) |
| `C:\datos\administracion` | Administrators / Dirección<br>Administración<br>Comerciales | **Control Total**<br>**Modificar** (*Modify*)<br>**Lectura** (*Read*) |

1. Abre las propiedades de cada carpeta compartida y revisa la pestaña **Seguridad**.
2. Comprueba que únicamente figuran los grupos explícitamente autorizados para cada departamento.
